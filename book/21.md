## 21.1　抽選販売機能を追加する

**初花**: 抽選って、申し込んだ人の中から当選者を選ぶんだよね。席はいつ押さえるの？

**マリゴールド**: そこを最初に決めよう。申し込んだ時点で押さえると、落選する人の席まで一時的に押さえることになる。**申し込んだだけでは席を押さえず、抽選のときにまとめて押さえる**、にするよ。ルールに書いておこう。

`docs/domain/rules.md`（抜粋）:

```markdown
| R-13 | 抽選のイベントは、申し込んだだけでは席を押さえない。抽選で、乱数の順に残席に入る申込から当選にし、当選者には仮予約を作る。先着の申込は受け付けない |
```

**初花**: 「乱数の順に」って、テストできるの？ 毎回結果が変わるよね。

**マリゴールド**: 乱数を **外から渡す** んだ。第7章で「今」を引数でもらったのと同じ考え方だよ。同じ乱数の種を渡せば、同じ結果になる。先にドメインのテストを書こう。

```ruby
module Ticketing
  # 抽選。申込を乱数の順に並べ、残席に入る申込から当選にする（R-13）
  class Lottery
    Entry = Data.define(:id, :count)
    Result = Data.define(:winners, :losers)

    def initialize(seats:)
      @seats = seats
    end

    # random を渡すので、同じ乱数の種なら同じ結果になる
    def draw(entries, random:)
      remaining = @seats
      winners, losers = entries.shuffle(random: random).partition do |entry|
        next false if entry.count.to_i > remaining

        remaining -= entry.count.to_i
        true
      end
      Result.new(winners: winners, losers: losers)
    end
  end
end
```

```ruby
module Ticketing
  # 抽選の申込（Lottery::Entry）を lottery_entries テーブルに保存し、読み込む
  class LotteryEntryRepository
    def add(event_id:, applicant:, count:)
      LotteryEntry.create!(event_id: event_id, name: applicant.name, email: applicant.email.to_s,
                           quantity: count.to_i)
    rescue ActiveRecord::RecordNotUnique
      raise EnterLottery::AlreadyEntered
    end

    # まだ抽選していない申込を、申し込んだ順に返す
    def entered_for(event_id)
      LotteryEntry.entered.where(event_id: event_id).order(:id).map do |record|
        Lottery::Entry.new(id: record.id, count: ReservationCount.new(record.quantity),
                           applicant: Applicant.new(name: record.name, email: record.email))
      end
    end

    def mark_won(entry, reservation_id:)
      LotteryEntry.where(id: entry.id).update_all(status: "won", reservation_id: reservation_id, updated_at: Time.current)
    end

    def mark_lost(entries)
      LotteryEntry.where(id: entries.map(&:id)).update_all(status: "lost", updated_at: Time.current)
    end
  end
```

```ruby
module Ticketing
  # 抽選する。当選者には仮予約を作って席を押さえ、落選者は落選にする（R-13）
  class DrawLottery
    def initialize(entries: LotteryEntryRepository.new, inventories: InventoryRepository.new,
                   reservations: ReservationRepository.new, sales_infos: SalesInfoReader.new)
      @entries = entries
      @inventories = inventories
      @reservations = reservations
      @sales_infos = sales_infos
    end

    def call(event_id:, random: Random.new, now: Time.current)
      ApplicationRecord.transaction do
        inventory = @inventories.find(event_id, lock: true)
        result = Lottery.new(seats: inventory.remaining_seats).draw(@entries.entered_for(event_id), random: random)

        price = @sales_infos.find(event_id).price
        result.winners.each { |entry| reserve_for(entry, inventory, price, now) }
        @entries.mark_lost(result.losers)
        @inventories.save(inventory)
        result
      end
    end

    private

    def reserve_for(entry, inventory, price, now)
      inventory.reserve(entry.count)
      reservation = @reservations.add(
        Reservation.apply(event_id: inventory.event_id, applicant: entry.applicant, count: entry.count, price: price,
                          reserved_at: now)
      )
      @entries.mark_won(entry, reservation_id: reservation.id)
      DomainEvents.publish(ReservationCreated.new(reservation_id: reservation.id, event_id: inventory.event_id,
                                                  status: reservation.status, occurred_at: now))
    end
  end
end
```

```ruby
module Ticketing
  # キャンセル待ち。空いた席に、登録の古い順から、入る人数の人を案内する（R-14）
  class Waitlist
    class Entry < Data.define(:id, :count, :applicant)
      def initialize(id:, count:, applicant: nil)
        super
      end
    end

    # entries は登録の古い順
    def initialize(entries)
      @entries = entries
    end

    def offers_for(seats)
      remaining = seats
      @entries.select do |entry|
        next false if entry.count.to_i > remaining

        remaining -= entry.count.to_i
        true
      end
    end
  end
end
```

```ruby
module Ticketing
  # 席が戻ったら、キャンセル待ちの人に案内する。登録の古い順に、入る人数の人へ仮予約を作る（R-14）
  class OfferReleasedSeats
    def initialize(entries: WaitlistEntryRepository.new, inventories: InventoryRepository.new,
                   reservations: ReservationRepository.new, sales_infos: SalesInfoReader.new)
      @entries = entries
      @inventories = inventories
      @reservations = reservations
      @allocate = AllocateSeats.new(reservations: reservations)
      @sales_infos = sales_infos
    end

    def call(event_id:, now: Time.current)
      ApplicationRecord.transaction do
        inventory = @inventories.find(event_id, lock: true)
        candidates = skip_already_reserved(event_id, @entries.waiting_for(event_id))

        price = @sales_infos.find(event_id).price
        Waitlist.new(candidates).offers_for(inventory.remaining_seats).each do |entry|
          reservation = @allocate.call(inventory: inventory, applicant: entry.applicant, count: entry.count,
                                       price: price, now: now)
          @entries.mark_offered(entry, reservation_id: reservation.id)
        end
        @inventories.save(inventory)
      end
    end

    private

    # すでに有効な予約がある人は、案内せずに飛ばす（R-03）
    def skip_already_reserved(event_id, entries)
      reserved, candidates = entries.partition do |entry|
        @reservations.active_exists?(event_id: event_id, email: entry.applicant.email)
      end
      @entries.mark_skipped(reserved)
      candidates
    end
  end
end
```

```ruby
module Ticketing
  # 主催者ごとの予約のルール。1回の予約の人数の上限（R-02）と、返金期限（R-09）
  class ReservationPolicy < Data.define(:max_count, :refund_hours_before_start)
    class TooManyAttendees < BusinessRuleViolation
      attr_reader :max_count

      def initialize(max_count)
        @max_count = max_count
        super("1回の予約は#{max_count}人までです")
      end
    end

    def initialize(max_count:, refund_hours_before_start:)
      unless max_count.between?(ReservationCount::MIN, ReservationCount::MAX)
        raise ArgumentError, "1回の予約の上限は#{ReservationCount::MIN}〜#{ReservationCount::MAX}人で決めてください"
      end

      super
    end

    DEFAULT = new(max_count: 4, refund_hours_before_start: CancellationDeadline::HOURS_BEFORE_START)

    def ensure_count_allowed!(count)
      raise TooManyAttendees, max_count if count.to_i > max_count
    end

    def cancellation_deadline(starts_at)
      CancellationDeadline.new(starts_at: starts_at, hours_before_start: refund_hours_before_start)
    end
  end
end
```

```ruby
module Ticketing
  # 抽選の当選やキャンセル待ちの案内で、申込者のために席を押さえて仮予約を作る。
  # 呼び出す側のトランザクションの中で、ロックした残席を渡して使う
  class AllocateSeats
    def initialize(reservations: ReservationRepository.new)
      @reservations = reservations
    end

    def call(inventory:, applicant:, count:, price:, now:)
      inventory.reserve(count)
      reservation = @reservations.add(
        Reservation.apply(event_id: inventory.event_id, applicant: applicant, count: count, price: price,
                          reserved_at: now)
      )
      DomainEvents.publish(ReservationCreated.new(reservation_id: reservation.id, event_id: inventory.event_id,
                                                  status: reservation.status, occurred_at: now))
      reservation
    end
  end
end
```

```ruby
module Ticketing
  # 抽選する。当選者には仮予約を作って席を押さえ、落選者は落選にする（R-13）
  class DrawLottery
    def initialize(entries: LotteryEntryRepository.new, inventories: InventoryRepository.new,
                   allocate: AllocateSeats.new, sales_infos: SalesInfoReader.new)
      @entries = entries
      @inventories = inventories
      @allocate = allocate
      @sales_infos = sales_infos
    end

    def call(event_id:, random: Random.new, now: Time.current)
      ApplicationRecord.transaction do
        inventory = @inventories.find(event_id, lock: true)
        result = Lottery.new(seats: inventory.remaining_seats).draw(@entries.entered_for(event_id), random: random)

        price = @sales_infos.find(event_id).price
        result.winners.each do |entry|
          reservation = @allocate.call(inventory: inventory, applicant: entry.applicant, count: entry.count,
                                       price: price, now: now)
          @entries.mark_won(entry, reservation_id: reservation.id)
        end
        @entries.mark_lost(result.losers)
        @inventories.save(inventory)
        result
      end
    end
  end
end
```

```markdown
# 0003 主催者ごとの予約のルールを、値オブジェクトにする

- 状態: 採用（第21章）

## 背景

主催者によって、1回の予約の人数の上限（家族向けは6人まで、など）と、返金期限（前日まで、など）を変えたい。これまでは R-02（4人まで）と R-09（72時間前）をコードの定数で持っていた。

## 決めたこと

主催者（`organizers`）が決めたルールを、予約のコンテキストでは `Ticketing::ReservationPolicy`（値オブジェクト）として扱う。`SalesInfoReader` がイベントの主催者から読み替え、主催者のいないイベントは `ReservationPolicy::DEFAULT`（4人・72時間）にする。`ReservationCount` は、サービス全体の上限（1〜10人）だけを守る。

## ほかに考えた案

| 案 | 選ばなかった理由 |
|----|----------------|
| `ReservationCount` の上限を主催者ごとに変える | 値オブジェクトを作るたびに主催者が要り、ドメインのテストが重くなる |
| フォームのバリデーションで、主催者の上限を確かめる | APIやキャンセル待ちから申し込むときに通らない。上限は入力の形ではなく業務のルール |

## 結果

- 「4人まで」は入力の形の誤り（422）から、業務の誤り（APIでは409 `too_many_attendees`）に変わった
- 画面のメッセージも、業務の誤りとして「人数は1回の予約で4人までです」に変え、見出しも「入力エラー」ではなく「予約できませんでした」にする
  - はじめは、これまでと同じ「人数は4以下の値にしてください」を出すつもりだった。しかしそれでは、入力の範囲（`ReservationCount` の10人）の「人数は10以下の値にしてください」と同じ形になる。21人で申し込むと「10以下」、10人に直すと今度は「4以下」と言われ、利用者には上限が2つあるように見えてしまう
- 返金の案内も、固定の「開催3日前」ではなく、`CancellationDeadline#refund_until` から返金期限の日時を示す
```
