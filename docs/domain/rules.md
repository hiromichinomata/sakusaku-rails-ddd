# うめチケット 業務ルール一覧

ルールには ID を振り、テスト（`spec/requests/business_rules_spec.rb`）の説明に同じ ID を書く。

| ID | ルール |
|----|-------|
| R-01 | 有効な予約の人数の合計は、イベントの定員を超えない |
| R-02 | 1件の予約の人数は1〜4人 |
| R-03 | 同じイベントに、同じメールアドレスの有効な予約は1件まで |
| R-04 | 申込は、イベントの開始時刻の前まで受け付ける。開始時刻ちょうどからは受け付けない |
| R-05 | 有料イベントの申込は仮予約になる。仮予約の作成から15分後まで（ちょうどを含む）に支払うと、予約確定になる |
| R-06 | 無料イベントの申込は、その場で予約確定になる |
| R-07 | 支払い期限を過ぎた仮予約は期限切れになり、席を戻す |
| R-08 | キャンセルできるのは、仮予約と予約確定だけ |
| R-09 | 開始時刻の72時間前まで（ちょうどを含む）に予約確定をキャンセルすると、支払った全額を返金する。それより後は返金しない |
| R-10 | キャンセル済み・期限切れの予約は、予約確定に戻せない |
| R-11 | 主催者は、定員を予約済みの人数より少なくできない |
| R-12 | 予約の料金は、申し込んだときのイベントの料金で決まる。あとでイベントの料金が変わっても、予約の支払い金額は変わらない |
| R-13 | 抽選のイベントは、申し込んだだけでは席を押さえない。抽選で、乱数の順に残席に入る申込から当選にし、当選者には仮予約を作る。先着の申込は受け付けない |
| R-14 | 満席のイベントには、キャンセル待ちに登録できる。席が戻ったら、登録の古い順に、残席に入る人数の人へ仮予約を作って知らせる。すでに有効な予約がある人は飛ばす |
