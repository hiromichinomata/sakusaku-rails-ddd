# うめチケット 用語集

業務で使う言葉と、コードでの名前の対応。迷ったら、この表の言葉で話し、この表の名前で書く。

## 人

| 用語 | 意味 | コードでの名前 | 使わない言葉 |
|------|------|--------------|-------------|
| 主催者 | イベントを企画し、登録する人・団体 | `organizer` | 管理者、オーナー |
| 申込者 | 予約を申し込み、支払う人。名前とメールアドレスで表す | `applicant`（今は `Reservation#name`・`#email`） | 顧客、ユーザー、会員 |
| 参加者 | イベントに実際に来る人。1件の予約に1〜4人 | `attendee` | お客さん |

## 予約のライフサイクル

| 用語 | 意味 | コードでの名前 |
|------|------|--------------|
| 申込（申し込む） | 申込者が、席を確保するよう依頼すること | `reserve` |
| 予約 | 申込によって作られる記録。仮予約から、確定・キャンセル・期限切れのどれかで終わる | `Reservation` |
| 仮予約 | 有料イベントで、支払いを待っている予約。席は確保されている | `pending` |
| 予約確定 | 支払いが済んだ（無料なら申込と同時の）予約 | `confirmed` |
| キャンセル | 申込者が予約を取りやめること。仮予約・予約確定のときだけできる | `cancel` / `canceled` |
| 期限切れ | 支払い期限までに支払われなかった仮予約 | `expire` / `expired` |
| 有効な予約 | 席を使っている予約。仮予約と予約確定 | `active` |

## 席とお金

| 用語 | 意味 | コードでの名前 |
|------|------|--------------|
| 定員 | イベントに入れる参加者の上限 | `capacity` |
| 人数 | 1件の予約の参加者の数（1〜4） | `quantity`（第8章で見直す） |
| 予約済みの人数 | 有効な予約の人数の合計 | `reserved_count` |
| 残席 | 定員 − 予約済みの人数 | `remaining_seats` |
| 料金 | 参加者1人あたりの金額（円） | `price` |
| 支払い金額 | 料金 × 人数 | `total_price` |
| 支払い | 決済サービスで支払い金額を受け取ること | `Payment`・`charge` |
| 返金 | 支払い金額を申込者に戻すこと。全額だけで、一部の返金はない | `refund` |

## 期限

| 用語 | 意味 |
|------|------|
| 受付期間 | 申込を受け付ける期間。イベントの開始時刻の前まで（開始時刻ちょうどからは受け付けない） |
| 支払い期限 | 仮予約の作成から15分後。ちょうど15分後までは支払える |
| 返金期限 | 開始時刻の72時間前。ちょうど72時間前までにキャンセルすれば全額返金する |

## 決めたこと

- 「顧客」は、申込者と参加者のどちらを指すか分からないので使わない
- 「購入」は使わない。支払いのない無料イベントもあるので、「予約確定」で揃える
- 「3日前」は、カレンダーの日付ではなく **開始時刻の72時間前** とする（主催者に確認済み）
- 「〜まで」の期限は、**ちょうどの時刻を含む**
