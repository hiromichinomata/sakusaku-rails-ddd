# 0002 キャンセル待ちは、席が戻ったドメインイベントで動かす

- 状態: 採用（第21章）

## 背景

キャンセルや期限切れで席が戻ったら、キャンセル待ちの人に案内したい。席が戻る場所は、キャンセル・期限切れ・（将来の）主催者の定員の変更と、いくつもある。

## 決めたこと

`ReservationCanceled`・`ReservationExpired` を購読する `Ticketing::WaitlistSubscriber` が、`Ticketing::OfferReleasedSeatsJob` を積む。ジョブの中で、残席をロックしてから、登録の古い順に入る人数の人へ仮予約を作る（`Ticketing::OfferReleasedSeats`）。

## ほかに考えた案

| 案 | 選ばなかった理由 |
|----|----------------|
| `CancelReservation` と `ExpireReservation` の中で、キャンセル待ちに案内する | キャンセルのトランザクションが長くなる。席が戻る場所が増えるたびに、そこにも書く必要がある |

## 結果

- キャンセルのユースケースは、キャンセル待ちのことを知らない
- 案内はコミットのあとのジョブなので、キャンセルの直後に別の人が先着で申し込むと、その人が先に席を取ることがある（業務として許すことにした）
